03

ตอบคำถามท้ายแบบฝึกหัด

a

นักศึกษาใช้ AI ช่วยส่วนไหนบ้าง ตอบตามความเป็นจริง

ใช้ AI ช่วยในการ Refactor โค้ดในส่วนของ ArmWorkoutEngine.ts เพื่อแยก Logic การนับรอบ (Algorithm แบบ Rule-based) ออกจาก UI ให้เป็นไปตามหลัก Modular design อย่างถูกต้องตามโจทย์ รวมถึงช่วยแนะนำวิธีการเรียกใช้ TTS และ Haptics ผ่าน Engine
b

ส่วนใดบ้างที่นักศึกษาปรับแก้ไขเอง

ทำการ Build ลงอุปกรณ์ Android จริงและทดสอบเพื่อปรับจูนค่า Threshold เช่น ค่าพารามิเตอร์ UP_TH, DOWN_TH, MIN_MS, MAX_MS ของเซ็นเซอร์ให้เหมาะสมกับการยกแขนในชีวิตจริง ปรับแต่ง CSS และสีสันของ UI เพิ่มเติม และเป็นผู้ทดสอบและบันทึกวิดีโอสาธิตการทำงานจริงด้วยตนเอง
